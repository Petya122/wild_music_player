# Security

## Reporting a problem

Please don't open a public issue for security problems. Use GitHub's private reporting instead:
**Security** tab → **Report a vulnerability**. Only the maintainer sees the report.

Helpful to include: the app version (Settings → Updates & Version), your Android version and phone, and
the steps to reproduce.

## Supported versions

Only the latest release gets fixes. The app updates itself from this repository's GitHub releases, which
are built by GitHub Actions and signed with the app's release key.
